# 航空写真からコースを切り取るときの決め事

PGM石岡ゴルフクラブを作ったときの試行錯誤から決めたルールです。新しいゴルフ場を作るときは毎回これに従い、最後のチェックリストを全部済ませてから出します。

## 1. 写真の使い方
- 全体の形はズーム17（1ピクセル約1m）、ティー台・バンカー・グリーンの細かいところはズーム18（約0.5m）で見る。
- 範囲はコースの外側まで少し広めに取る（道路の向こうのホールを見落とさないため）。
- 芝が枯れている季節の写真は判別が落ちるので、結果を見て必要ならしきい値を調整する。
- もやがかかって全体が青白い写真は、色の分布を基準の写真（PGM石岡、`ref_color.jpg`・`ref_color18.jpg`）に合わせてから判別する（segment.py が自動で判断。`--match` で強制）。
- 隣に別のゴルフ場がある場合は、クラブハウスの位置とホールのつながりで、どこまでが対象のコースかを最初に決める。

## 2. コースの範囲
- 道路で分かれた部分、コースの端の池、グリーン周りのバンカーも範囲に入れる。
- 練習場はホールにしない（横に広い、バンカーがほとんどない、クラブハウスの近く）。

## 3. それぞれの見分け方
| 地物 | 見分け方 |
|---|---|
| フェアウェイ | 芝の中で明るく、模様が少ないところ。取れないホールは中央をフェアウェイ扱いにする |
| グリーン | バンカーに囲まれた明るい丸いところ（今は半径約13ydの円の目安で描く） |
| バンカー | ズーム18で、明るく、緑っぽさがなく（LABのa*が高い）、まわりの芝より目立って明るいもの。枯れ芝・はげた所・道・屋根は外す |
| 池 | 暗くて模様が少なく、芝か林に接しているもの |
| 林 | ホールの中で、芝・池・バンカー以外の場所 |
| ティー台 | ズーム18で目で確かめる（角丸の明るい台）。木で隠れていたら、スコアカードの距離の位置を芝の上に寄せて仮に置き、仮であることを伝える |

## 4. ホールの線と番号
- 線は「一番後ろのティー → 曲がり角 → グリーンの中心」。池の先にグリーンがあれば、必ずグリーンまで伸ばす。
- 番号はレイアウト図（楽天GORAの「コースレイアウト」のスクリーンショット）を最優先。ないときは次の手がかりで決める。
  - 1番・10番のティーと、9番・18番のグリーンはクラブハウスの近く
  - 前のホールのグリーンの近くに次のホールのティー
  - スコアカードのパーと距離、コースガイドのドッグレッグの向き・池の位置
- 線どうしが交差したら、どこかの読み違い。
- 線の長さは一番後ろのティーの距離に合わせる。100yd以上ずれるホールは無理に合わせず、番号か位置を見直す。

## 5. 切り取り方（見た目）
- ホールの線に沿ったなめらかな楕円で切る。幅は左右45yd、ティーの後ろとグリーンの奥に22yd。
- 縁は濃い林の帯にして、外側の隣のホール・林・池・バンカーは70ydまで薄く描く（レイアウト図風）。
- 形は全部角のない曲線にする（輪郭をとる前にぼかし、アプリでも曲線で描く）。
- ティー台のまわりと、ティーからフェアウェイまでの通り道は林にしない。

## 6. 高低差
- 国土地理院の標高データ（5mメッシュ）を使い、選んだティーからの差で計算する。
- 落とし所が1.5°以上傾いていたら、ルート解説に傾斜（左足上がり・つま先下がりなど）を出す。

## 7. 出す前のチェックリスト
- [ ] 全ホールの距離がスコアカードに合う（100yd以上のずれがない）
- [ ] ホールの線どうしが交差していない
- [ ] アプリで数ホールの画面を見る（池・バンカー・ティー台がきれいに出ているか）
- [ ] ティーを切り替えて、ティーが台の上に乗るか
- [ ] 全18ホールで表示とデータ攻略ルートにエラーがない
- [ ] まだ目安の部分（グリーンの形、木で隠れたティーなど）を正直に伝える

## 決めている数字

| 楕円の伸ばし（ティー後ろ・グリーン奥） | 22yd | `AREA_PAD_YD` |

| 距離合わせの上限 | 100yd | `MAX_FIT_YD` |

| 傾斜を出す角度 | 1.5° | アプリ `lieText` |
